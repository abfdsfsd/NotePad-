# NotePad==

NotePad== is a lightweight Windows text editor implemented as a
self-contained batch file with an embedded PowerShell and Windows Forms
interface.

The application is designed to provide a practical desktop editing
environment without requiring a traditional installer or external
runtime beyond components included with supported Windows installations.

# Keyboard Shortcuts

  Shortcut         Action
  ---------------- ----------------------
  `Ctrl+N`         New document
  `Ctrl+O`         Open file
  `Ctrl+S`         Save
  `Ctrl+Shift+S`   Save As
  `Ctrl+F`         Find / Replace
  `F3`             Find next
  `Shift+F3`       Find previous
  `Ctrl+G`         Go to line
  `Ctrl+T`         Toggle theme
  `F5`             Insert date and time
  `F11`            Toggle full screen
  `Ctrl+Shift+P`   Command palette
  `Ctrl+Shift+I`   Statistics
  `Ctrl+Shift+H`   Hash
  `Ctrl+P`         Print

# Supported File Types

NotePad== recognizes the following extensions for syntax highlighting:

  Language     Extensions
  ------------ ------------------------------
  JavaScript   `.js`, `.jsx`, `.ts`, `.tsx`
  Python       `.py`
  PowerShell   `.ps1`, `.psm1`
  Batch        `.bat`, `.cmd`
  JSON         `.json`
  SQL          `.sql`
  C#           `.cs`
  C/C++        `.cpp`, `.c`, `.h`, `.hpp`
  Java         `.java`

Other files can still be opened and edited as plain text.

# Data and Privacy

NotePad== operates locally on the user's computer. Files opened in the
editor are read from and saved to the local filesystem.
